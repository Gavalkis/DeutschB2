# Deutsch bis B2 - Offline-first Android

Функции MVP:
- локальные уроки A1-B2;
- словарь с артиклем, множественным числом, переводом и примерами;
- практика активного вспоминания;
- локальное хранение прогресса;
- Android TextToSpeech;
- камера + ML Kit OCR/Image Labeling;
- большая часть функций работает без сети после установки и загрузки системного немецкого TTS.

## Сборка
Открой репозиторий в GitHub и запусти Actions -> Build Android APK -> Run workflow.
Готовый APK появится в Artifacts.
